# Prato Leve

Site estático (HTML/CSS/JS, sem build) com receitas low FODMAP: ver as receitas, favoritar,
escolher o que quer comer e gerar a lista de compras das receitas escolhidas.

- Receitas pesquisadas em fontes sobre a dieta low FODMAP (Monash University, Michigan Medicine,
  Tua Saúde, Vitat, Nutritotal) e adaptadas para ingredientes fáceis de achar no Brasil, sem alho e cebola.
- Conteúdo em `data.js`. Cada ingrediente é `[texto, produto do mercado, opcional?]`; o produto
  precisa estar em `PRODUTOS` com a sua categoria.
- Favoritas, receitas escolhidas e itens marcados ficam salvos só no navegador do aparelho (localStorage).
- Publicado pelo GitHub Pages a partir da branch `main`.

Não substitui a orientação de nutricionista. As porções seguem as quantidades baixas em FODMAP da Monash.
